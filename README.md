# LaSalle-OOPD-Olympics

This is a university project for the Object-Oriented Programming course. LA28 Games Lab is a platform to simulate the Los Angeles 2028 Olympic Games.

**What this program can do:**
- Manage country delegations and register athletes.
- Load and list sports competitions.
- Simulate results based on athlete skills and a luck factor.
- Create a final medal table (gold, silver, bronze).

All information is saved locally in JSON files (`delegations.json`, `athletes.json`, `competitions.json`).
